# Dữ liệu VN1

Dữ liệu **không có trên GitHub**. Tải 5 file CSV của VN1 Forecasting (Phase 0/1 Sales + Price, Phase 2 Sales)
và đặt vào `VN1/data/raw/vn1-forecasting/` (ví dụ `VN1/data/raw/vn1-forecasting/Phase 0 - Sales.csv`).
Nếu để dữ liệu ở chỗ khác, đặt biến môi trường `VN1_DATA_DIR` trỏ tới thư mục chứa 5 file CSV.
